## 0. 一分钟搞清在做什么

```text
游戏 / JS
  → NativeBility：widget/default/<api>
    → WidgetCommon（主 App）：写 App Group 快照 + 请求系统刷新
      → HYWidgetExtension + WidgetUI：读快照并渲染
        →（iOS 16 公会配置）HYWidgetIntentExtension + IntentDefinition
```

| 项 | 说明 |
|----|------|
| 系统下限（能力侧） | **iOS 16.1+**（适配器 `isEnabled`） |
| JS 模块名 | `widget` |
| 适配器 | `Plugin_widget` → `PluginAdapter_widget` 等 |
| App Group | **`group.` + 主包 Bundle ID** |
| 花园示例 | 主包 `cn.lbwdhysj.gf.ios`；扩展 `…ios.HYWidget`；Intent `…ios.HYWidgetIntent` |
| Pod 来源 | **内网 Git remote**（同事按此接入即可） |

**架构三层（不是「只引一个 Pod」）：**

```text
WidgetCommon  —— 主 App + 桌面扩展都要（写/读快照）
WidgetUI      —— 仅桌面扩展（UI，禁止链进主 App）
Intent 扩展   —— post_install 自动挂（公会竞赛 iOS 16 配置）
```

## 3. Podfile 怎么配（花园模板）

路径：`/Users/lin/Documents/HuaYuann/build/ios/proj/Podfile`

### 3.1 模式开关

同事接入统一用 **remote**：

```ruby
# 'remote' = 内网 git（同事 / 发布 / CI）
# 'none'   = 不接小组件 / 控制中心相关 Pod
WIDGET_MODE = 'remote'
WIDGET_GIT_BASE = 'ssh://git@192.168.13.252:8022/modo_ios'
```

> 花园里 **控制中心** 也走同一 `WIDGET_MODE`（见《控制中心接入文档》）。只关小组件、保留控制中心时要单独拆开关（当前模板未拆）。

### 3.2 主 App

```ruby
if WIDGET_MODE == 'remote'
  pod 'WidgetCommon', :git => "#{WIDGET_GIT_BASE}/mdwidgetcommon.git"
  # ControlWidgetCore 见控制中心文档；不要在主 App 引 WidgetUI
end
```

### 3.3 桌面小组件扩展

```ruby
# 继承根 platform 12.0，不要在这里写 platform :ios,'16.1'
target 'HYWidgetExtension' do
  if WIDGET_MODE == 'remote'
    pod 'WidgetUI', :git => "#{WIDGET_GIT_BASE}/mdwidgetui.git"
    pod 'WidgetCommon', :git => "#{WIDGET_GIT_BASE}/mdwidgetcommon.git"
  end
end
```

### 3.4 链接策略（pre_install，必做）

| Pod | 链接方式 | 原因 |
|-----|----------|------|
| WidgetCommon / WidgetUI | **static_framework** | 动态链在 iOS 15 主 App 有 JSONDecoder dyld 闪退风险 |
| ControlWidgetCore / Activity* | 动态（与小组件无关，别混） | 见灵动岛 / 控制中心文档 |

**禁止**：在 `HYWidgetExtension` 写 `platform :ios, '16.1'`  
→ 会拆出 `WidgetCommon-iOS12.0` 与 `WidgetCommon-iOS16.1`  
→ Archive：`Multiple commands produce .../WidgetCommon.framework`

真实最低系统用：

- Xcode Target **Deployment Target = 16.1**
- WidgetUI xcconfig / podspec 保持与根 `platform 12.0` 兼容

### 3.5 post_install：Intent Extension 自动安装

`WIDGET_MODE != 'none'` 且存在 WidgetUI 时：

```ruby
WidgetUI::IntentExtensionInstaller.install(
  project_path: File.join(__dir__, 'HuaYuann.xcodeproj'),
  sdk_root: installer.sandbox.pod_dir('WidgetUI'),
  app_target: 'HuaYuann',
  widget_target: 'HYWidgetExtension'
)
```

作用：

- 幂等创建 / 更新 **`HYWidgetIntentExtension`**
- 把 **唯一一份** `GuildCompetitionLegacy.intentdefinition` 编进主 App、桌面扩展、Intent 扩展
- Cocos **重新生成工程后必须再跑一次 `pod install`**

`WIDGET_MODE = 'none'` 时必须跳过这段（否则 `require Pods/WidgetUI/.../install` 报 LoadError）。花园已加守卫。

## 4. Xcode 工程步骤

### 4.1 建桌面 Widget Extension

1. File → New → Target → **Widget Extension**
2. 花园名：`HYWidgetExtension`
3. Bundle ID：`主包.HYWidget`
4. Deployment：**16.1**
5. Embed 到主 App
6. 与主 App 同一 App Group

### 4.2 扩展入口

花园：`build/ios/proj/HYWidget/HYWidgetBundle.swift`

```swift
import WidgetKit
import SwiftUI
import WidgetUI

@main
struct HYWidgetBundle: WidgetBundle {
    var body: some Widget {
        WidgetUIDesktopBundle.allDesktopWidgets()
    }
}
```

当前常见 6 个 kind（概念）：

- 种花：Small / Medium  
- 珍珠：Small / Medium  
- 公会竞赛：Small / Medium  

具体 kind 字符串以 WidgetUI 为准（如 `HYGardenFlowerSmall` 等）。

### 4.3 Intent Extension（一般不用手建）

- Intent 真源只在 **WidgetUI Pod** 内维护（`GuildCompetitionLegacy.intentdefinition`）
- Handler / Info 模板也在 Pod：`Integration/HYWidgetIntentExtension/`
- Bundle ID 规则：`主包.HYWidgetIntent`
- Deploy：**16.1**
- **业务工程不要复制一份 intentdefinition 自己改**；改 SDK 仓库后再 `pod install`

用途：iOS 16.x 长按公会竞赛小组件配置「目标」等。

### 4.4 App Group / entitlements

- 主 App + `HYWidgetExtension`（+ Intent 扩展若需要共享）同一 group
- 花园：`group.cn.lbwdhysj.gf.ios`
- 路径示例：`native/engine/ios/HuaYuann.entitlements`、`HYWidgetExtension.entitlements`

可选：JS `dataDict.appGroupId` 覆盖；默认 `group.{包名}`。

## 5. NativeBility / JS 调用

### 5.1 路径与 API

```text
widget / default / <api>
```

| API | 作用 |
|-----|------|
| `request` | 写入 / 启动一类业务快照 |
| `update` | 更新快照 |
| `end` | 结束 / 清理一类业务 |
| `query` | 查询当前桌面已装 kind / family / types |
| `getInfo` | 读取「点小组件进 App」的一次性信息 |

### 5.2 业务 type（统一走 request / update / end）

| type | 说明 |
|------|------|
| `flower_plant` / `flower_sale` / `flower_water_drop` | 种花三栏（注意协议版本，常见 v3） |
| `competition` | 公会竞赛（**不是**旧名 `flower_competition`） |
| `pearls` | 珍珠；字段如 `pearlCount`、`buttonTitle`、`slots[4]` |

字段细节以仓库 `docs/小组件` 与 `widget-implementation.md` 为准，接入时不要用旧字段硬猜。

### 5.3 快照文件（App Group 下 `widget/`）

常见文件：

- `widget_snapshot.json`（种花等）
- `pearl_snapshot.json`
- `guild_competition_snapshot.json`

写盘习惯：encode → 临时文件 → move；成功后触发 `reloadGardenWidgets()`。

### 5.4 点击进 App → getInfo

```text
用户点小组件
  → WidgetUI 拼 open URL（action / family / isEdit 等）
  → 主 App 打开 → PluginMgr.handleWidgetLaunchURL
  → 写入 App Group（WidgetLaunch）
  → 游戏调 widget/default/getInfo 读并消费（TTL ≈ 30s）
```

注意：公会竞赛「编辑」类 `isEdit` 可能按 kind 独立、立即消费，和普通点击略有差别。

### 5.5 query 返回（概念）

```json
{
  "widgets": [
    { "kind": "…", "family": "systemSmall", "types": ["flower_plant"] }
  ]
}
```

不要再按旧协议只读 `data` 字段。

## 6. 推荐操作流程（给同事抄）

```text
1. 建 HYWidgetExtension（Deploy 16.1，Bundle = 主包.HYWidget）
2. Podfile：WIDGET_MODE=remote
   - 主 App：WidgetCommon（git，不要 WidgetUI）
   - 扩展：WidgetUI + WidgetCommon（git）
3. pre_install：Widget* 强制静态库
4. 扩展 Target 不要单独写 platform :ios,'16.1'
5. pod install（自动挂 Intent Extension）
6. 主/扩展 App Group = group.<主包ID>
7. 扩展 @main → WidgetUIDesktopBundle.allDesktopWidgets()
8. 真机添加 6 类小组件，JS request 后看是否刷新
9. 点小组件 → getInfo 有 action/family → 再调为空
10. iOS 16：长按公会竞赛可配置目标（Intent）
```

Cocos 重生 `build/ios/proj` 后：**必须再 `pod install`**，否则 Intent / 工程引用会丢或指到错误路径。

## 8. 常见踩坑

| 现象 | 原因 | 处理 |
|------|------|------|
| Archive：Multiple commands produce WidgetCommon | Extension 单独 `platform 16.1` | 删掉该 platform，只改 Target Deploy |
| iOS 15 主 App 启动闪退（JSONDecoder / dyld） | WidgetCommon 被动态链 | pre_install 强制静态 |
| 低系统启动加载异常 | 主 App 误引 WidgetUI | 主 App 只留 WidgetCommon |
| 点组件无 getInfo | scheme / App Group / URL query 未解析 | 对照 WidgetUI LaunchRoute 与 PluginMgr |
| 公会配置无效 | Intent 定义被业务复制改坏 / 未再 pod install | 只改 SDK 仓库，再 pod install |
| `WIDGET_MODE=none` 后 pod install 崩 | post_install 仍 require WidgetUI install | 加 `WIDGET_MODE != 'none'` 守卫 |
| pod install 拉不下来 | 内网 Git / SSH 权限 | 确认能访问 `192.168.13.252:8022` |
| pbxproj 出现本机绝对路径 | 误把联调路径写进工程并提交 | 发布保持 remote；勿提交本机绝对路径 |

## 10. 与灵动岛 / 控制中心

| | 灵动岛 | 桌面小组件 | 控制中心 |
|--|--------|------------|----------|
| 开关 | `ACTIVITY_MODE` | `WIDGET_MODE` | 同 `WIDGET_MODE` |
| 扩展 Target | `*LAExtension` | `HYWidgetExtension` (+Intent) | `HYControlWidgetExtension` |
| 链接 | Activity* **动态** | Widget* **静态** | Control **动态** |
| JS | `live_activity` | `widget` | `control` |

桌面小组件与控制中心 **分开 Extension**，不要塞进同一个 Bundle。
