## 0. 一分钟搞清在做什么

```text
游戏 / JS
  → NativeBility：live_activity/default/<api>
    → ActivitySDK（主 App）：启 / 更 / 停 / 查 / 权限
      → App Group 写图片与数据
        → HuaYuanLAExtension（ActivityUI）：真正画岛 / 锁屏卡片
```

| 项 | 说明 |
|----|------|
| 系统下限 | **iOS 16.1+** |
| JS 模块名 | `live_activity` |
| 适配器 | `Plugin_activity` → `PluginAdapter_activity` |
| App Group | **`group.` + 主包 Bundle ID**（主 App 与扩展必须一致） |
| 花园示例包名 | `cn.lbwdhysj.gf.ios` → Group：`group.cn.lbwdhysj.gf.ios` |
| Pod 来源 | **内网 Git remote**（同事按此接入即可） |

## 1. SDK 组成（谁给谁用）

| Pod | 谁用 | 作用 | 内网 Git |
|-----|------|------|----------|
| **ActivitySDK** | **主 App** | `ActivityMgr`：启/更/停/查/权限 | `ssh://git@192.168.13.252:8022/modo_ios/activitysdk.git` |
| **ActivityCoreDate** | 主 App + LA 扩展 | 共享 Attributes / 模型 | `…/activitycoredate.git` |
| **ActivityUI** | **仅 LA 扩展** | `ActivityWidgetBundle` UI | `…/activityui.git` |

依赖关系：

- `ActivitySDK` → `ActivityCoreDate`
- `ActivityUI` → `ActivityCoreDate`

未链上 ActivitySDK 时，NativeBility 适配器会打日志类似：`ActivitySDK-->未引入ActivitySDK`，能力不可用。

## 3. Podfile 怎么配（花园模板）

花园路径：`/Users/lin/Documents/HuaYuann/build/ios/proj/Podfile`

### 3.1 模式开关

同事接入统一用 **remote**：

```ruby
# 'remote' = 内网 git（同事 / 发布 / CI）
# 'none'   = 不接灵动岛 SDK
ACTIVITY_MODE = 'remote'
ACTIVITY_GIT_BASE = 'ssh://git@192.168.13.252:8022/modo_ios'
```

### 3.2 主 App（在 `bilitySDK` 一类方法里）

```ruby
if ACTIVITY_MODE == 'remote'
  pod 'ActivitySDK', :git => "#{ACTIVITY_GIT_BASE}/activitysdk.git"
  pod 'ActivityCoreDate', :git => "#{ACTIVITY_GIT_BASE}/activitycoredate.git"
end
```

### 3.3 LA 扩展 Target

```ruby
target 'HuaYuanLAExtension' do   # 名字按项目改：工程名 + LAExtension
  if ACTIVITY_MODE == 'remote'
    pod 'ActivityCoreDate', :git => "#{ACTIVITY_GIT_BASE}/activitycoredate.git"
    pod 'ActivityUI', :git => "#{ACTIVITY_GIT_BASE}/activityui.git"
  end
end
```

### 3.4 必须：动态库（pre_install）

花园把下面两个强制成 **dynamic_framework**（否则常拿不到 `ActivitySDK-Swift.h`，OC 调不进）：

- `ActivitySDK`
- `ActivityCoreDate`

改完执行：

```bash
cd <工程>/build/ios/proj
pod install
```

## 4. Xcode 工程步骤（新项目从头做）

### 4.1 建 Live Activity / Widget Extension

1. Xcode → **File → New → Target → Widget Extension**
2. 命名习惯：**工程名 + LA**（花园：`HuaYuanLAExtension`）
3. Bundle ID：**`主包ID.HuaYuanLA`**（或团队约定后缀，须挂在主包前缀下）
4. Deployment Target：**16.1**
5. 勾选 Embed（主 App Embed Foundation Extensions）
6. 主 / 扩展 **同一 Team** 签名

### 4.2 扩展入口（只留 Bundle）

花园参考：`build/ios/proj/HuaYuanLA/HuaYuanLABundle.swift`

```swift
import WidgetKit
import SwiftUI
import ActivityUI

@main
struct HuaYuanLABundle: WidgetBundle {
    var body: some Widget {
        ActivityWidgetBundle().body
    }
}
```

其余模板文件可按项目裁剪；核心是 `@main` 走 `ActivityWidgetBundle`。

### 4.3 主 App Info.plist（必需）

以工程 `INFOPLIST_FILE` 指向的文件为准（花园常见：`CMakeFiles/HuaYuann.dir/Info.plist`）：

```xml
<key>NSSupportsLiveActivities</key>
<true/>
<key>NSSupportsLiveActivitiesFrequentUpdates</key>
<true/>
```

扩展 Info 可不强制加这两键；以主 App 为准。

### 4.4 App Group（主 + 扩展）

1. Signing & Capabilities → **App Groups**
2. 标识符：**`group.` + 主包 Bundle ID**
3. 主 App entitlements 与 LA 扩展 entitlements **完全一致**

花园：

- 主：`native/engine/ios/HuaYuann.entitlements`
- 扩展：`HuaYuanLAExtension.entitlements`
- 值：`group.cn.lbwdhysj.gf.ios`

NativeBility 写图时：

```objc
group.{[DeviceUtil getPackageName]}
```

包名不一致 → 容器为空 → 岛上没图。

### 4.5 URL Scheme（从岛点回 App）

需能打开类似：

```text
{yourScheme}://openFromLiveActivity?type=island|activityCard
```

花园 scheme 含 `huayuan6746321359`。点进 App 后尽快调 `getInfo`（一次性，TTL 约 30s）。

## 5. NativeBility / JS 调用

### 5.1 路径

```text
live_activity / default / <api>
```

API：

| API | 作用 |
|-----|------|
| `query` | 查当前活动 |
| `request` | 启动 |
| `update` | 更新 |
| `end` | 结束 |
| `getInfo` | 读取「从岛/卡片点进 App」的一次性信息 |

建议顺序：

1. 确认系统「实时活动」开关 / 权限
2. `request` → 业务中 `update` → 结束 `end`
3. 监听事件 **`liveActivityPushTokenUpdate`**（远程推送更新用）
4. 用户点岛进 App → 立刻 `getInfo`

### 5.2 request / update 关键字段（概念）

- `id`、`direction`、`time`（秒，映射 SDK 倒计时）
- `countdown` / `completed`：`title[]`、`subTitle[]`、`btn`、`tip`、`icon`(URL)
- 网络图会下到 App Group：`group.<包名>/live_activity/`，文件名 `MD5(url).png`

### 5.3 getInfo 成功形态（概念）

```json
{
  "scene": "liveActivity",
  "extra": { "type": "island" },
  "ts": 0
}
```

`type`：`island`（灵动岛）| `activityCard`（锁屏/横幅）。  
同一条 launch 信息一般只消费一次，再调多为空。

## 6. 推荐操作流程（给同事抄）

```text
1. 建 LA Extension Target（Deploy 16.1，Bundle = 主包.xxxLA）
2. Podfile：ACTIVITY_MODE=remote
   - 主：ActivitySDK + ActivityCoreDate（git）
   - 扩展：ActivityUI + ActivityCoreDate（git）
3. pre_install 强制 ActivitySDK / ActivityCoreDate 为动态库
4. pod install
5. 主 Info：NSSupportsLiveActivities + FrequentUpdates = true
6. 主/扩展 App Group = group.<主包ID>
7. 扩展 @main → ActivityWidgetBundle
8. 配 URL Scheme（openFromLiveActivity）
9. 真机：request 出岛 → 点岛 → getInfo 有值 → 再 getInfo 为空
```

Cocos 若重新生成 `build/ios/proj`，要重新核对：LA Target、Embed、Podfile、`pod install`。

- [ ] 主 Pod：ActivitySDK + ActivityCoreDate；扩展：ActivityUI + ActivityCoreDate（均为 remote git）

- [ ] （可选）能收到 `liveActivityPushTokenUpdate`

## 8. 常见踩坑

| 现象 | 常见原因 | 处理 |
|------|----------|------|
| 日志「未引入 ActivitySDK」 | 没 Pod，或静态库导致无 Swift Header | 检查 Pod + 动态库 |
| 岛上没图 / 容器 URL 空 | App Group ≠ `group.{包名}` | 对齐 entitlements 与包名 |
| 有权限不出岛 | 系统开关关、非真机、Deploy &lt; 16.1 | 查设置 + 真机 + Target |
| `request` 像没反应 | 无回调、未引 SDK、系统过低 | 看适配器日志与 callback |
| `getInfo` 一直空 | 没从岛点进、TTL 过、已消费 | 点岛立刻调；勿重复依赖 |
| pod install 拉不下来 | 内网 Git / SSH 权限 | 确认能访问 `192.168.13.252:8022` |

## 10. 与小组件 / 控制中心的关系

| | 灵动岛 | 桌面小组件 | 控制中心 |
|--|--------|------------|----------|
| Pod 开关 | `ACTIVITY_MODE` | `WIDGET_MODE` | 同 `WIDGET_MODE` |
| 系统 | 16.1+ | 16.1+ | **18+** |
| App Group | 同一 `group.<主包>` | 同左 | 同左 |
| JS 模块 | `live_activity` | `widget` | `control` |

三者可共存；App Group **共用同一 group**，但业务根键不同（灵动岛 launch / 图片目录独立）。
